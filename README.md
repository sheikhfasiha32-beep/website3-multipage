# Personal Portfolio Website

## About the Project
This is my personal portfolio website created to showcase my skills, projects, education, and contact information as a Computer Science student.

The website uses a forest-inspired color palette with a clean, modern, and professional design.

## Pages
- **Home (`index.html`):** Introduction and portfolio overview.
- **About (`about.html`):** Information about me, my background, and skills.
- **Projects (`projects.html`):** A collection of my projects.
- **Contact (`contact.html`):** Contact information and a contact form.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Design
- Forest green, sage green, ivory, and gold color palette
- Playfair Display and DM Sans typography
- Responsive layout for different screen sizes
- Separate page styling using CSS classes

## Project Structure
```text
portfolio/
├── index.html
├── about.html
├── projects.html
├── contact.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## AI Prompt Used

Create a complete, modern, responsive personal portfolio website for a Computer Science student using HTML5, CSS3, and plain JavaScript.

Include four pages:
- Home (`index.html`)
- About (`about.html`)
- Projects (`projects.html`)
- Contact (`contact.html`)

Use one shared CSS file named `style.css` and one shared JavaScript file named `script.js`.

### Design Requirements
Use a forest botanical color palette:
- Forest green: `#24352E`
- Deep forest: `#17271F`
- Sage green: `#A9B9A5`
- Ivory: `#F5F1E8`
- Gold: `#C5A66A`

Use Playfair Display for headings and DM Sans for body text. Make the design elegant, professional, clean, and responsive on desktop, tablet, and mobile.

### Page Requirements
1. **Home:** Introduce the portfolio owner and provide navigation to other pages.
2. **About:** Present background, education, and personal interests.
3. **Projects:** Display project cards and category filters.
4. **Contact:** Display contact information, social profile links, and a contact form with basic validation.

### Development Requirements
- Use semantic HTML5 and beginner-friendly code.
- Keep all pages connected through working navigation links.
- Scope page-specific CSS using body classes so one page's styling does not affect another page.
- Use JavaScript for interactive elements and form behavior.
- Use placeholders for contact details until real information is provided.
- Do not claim that the demo contact form sends messages to a server.
- Do not create extra CSS or JavaScript files.
- Keep the website accessible, readable, and mobile-friendly.
